# Security policy

## Reporting a vulnerability

Report it privately on GitHub: open this repository's Security tab and choose Report a vulnerability. Or email support@foxhoundapp.com with what you found, the version or commit, and steps to reproduce it. Please do not open a public issue for a vulnerability. The same contact is published at https://foxhoundapp.com/.well-known/security.txt (RFC 9116).

## Supported versions

Only the latest release is supported. Fixes ship as a new release.
